#### Translation
Box Placement

MegaBoy has a job of placing boxes numbered 1 to n.
A placement is considered correct if:

No two adjacent boxes are both odd or both even.
The boxes are arranged in increasing order by number.

Given n, determine the number of all possible correct placements modulo 1e9+7.

For N = 3 the correct placements are:
    1
    2
    3
    1 2
    2 3
    1 2 3

n = 4
    1
    2
    3
    4
    1 2
    2 3
    3 4
    1 4
    1 2 3
    2 3 4
    1 2 3 4

#### Solution

Consider DP approach:
dp_even[i] - number of valid placements made from numbers from 1 to i ending with an EVEN NUMBER
dp_odd[i] - number of valid placements made from numbers from 1 to i ending with an ODD number

base case:
dp_even[0] = 0
dp_odd[0] = 0
because we don't have valid placements of length 0

for each i:
if i is even:
dp_odd[i] = dp_odd[i-1] because we are not creating another placement ending with odd number

dp_even[i] =
1. i itself as a placement (i)
2. previous placements ending with even numbers (dp_even[i-1])
3. previous placements ending with odd numbers with i added to the end of each (dp_odd[i-1])

so dp_even[i] = 1 + dp_even[i-1] + dp_odd[i-1]

same for when i is odd:
dp_even[i] = dp_even[i-1]
dp_odd[i] = dp_even[i-1] + dp_odd[i-1]

we build our dp up to n without forgetting to take the modulo.
