#### Translation
Exchange

Zarif somehow obtained future USD exchange rates for the next N days. He wants to take advantage of this.
He knows [V,S] for each day, where V is how many USD he can get for 100 so'm and S is how many USD it costs to get 100 so'm.

Currently, he has 100 so‘m. Determine the maximum amount of money he can have at the end, assuming he can exchange between currencies optimally.

At the end, his money must be in so‘m.
#### Solution
We can solve this problem with dynamic programming. Note that it is always optimal to keep all of our money in one currency. So we can define dp[i][0] as the maximum amount of so'm we can have at the end of day i, and dp[i][1] as the maximum amount of USD we can have at the end of day i.

dp[0][0] = 100 // we start with 100 so'm

In each day we can either keep our money in the same currency, or exchange it to the other currency. So we can write the following transitions:
dp[i][0] = max(dp[i-1][0], dp[i-1][1] * 100 / S[i]) // buy so'm with USD
dp[i][1] = max(dp[i-1][1], dp[i-1][0] * V[i] / 100) // buy USD with so'm

The answer will be dp[N][0], since we want to end with so'm. The time complexity of this solution is O(N).
